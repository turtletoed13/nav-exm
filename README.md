# NAV-EXM

A large reference catalog of modern navbar directions for web apps, products, dashboards, games, and experimental interfaces.

> **Ordering rule:** #01–#50 are Apple-inspired directions. #51 onward intentionally branches into other visual languages: enterprise, editorial, brutalist, playful, futuristic, gaming, utility, spatial, retro, and experimental.

## How to use this catalog

Each entry is a **design direction**, not a claim that the named company or product uses the exact implementation described.

Use the catalog to pick a structural idea, then combine:
- **Shell:** where the navigation lives
- **Surface:** solid, translucent, glass, material, floating, edge-attached
- **State:** active, hover, selected, focused
- **Motion:** slide, morph, fade, spring, magnetic, scroll-reactive
- **Density:** compact, balanced, roomy
- **Responsive behavior:** collapse, transform, dock, overflow, command palette

# 01–50 — Apple-Inspired

These first 50 deliberately focus on the design language associated with modern Apple platform UI: restrained typography, semantic hierarchy, adaptive controls, translucent functional layers, tab/toolbar/sidebar relationships, scrolling minimization, and high-quality motion.

## 01. Liquid Glass Capsule
A floating translucent capsule with soft refraction, subtle edge highlights, and content visually moving beneath it.

## 02. iOS Floating Tab Bar
A compact rounded navigation group that floats above the page instead of touching the viewport edge.

## 03. iOS Prominent Tab
Four or five normal destinations plus one visually prominent destination that stays visually anchored.

## 04. Adaptive Tab-to-Sidebar
The same navigation model changes from compact tabs to a wider sidebar as available width increases.

## 05. macOS Toolbar
Window-level toolbar with navigation controls at the leading edge, title in the center, and utilities/actions on the trailing edge.

## 06. macOS Unified Toolbar
A single calm horizontal control layer blending title, navigation, search, and actions into one coherent bar.

## 07. Safari-Style Minimal Bar
Almost no chrome: brand/title on one side, compact controls on the other, with content doing most of the visual work.

## 08. Finder Sidebar + Toolbar
Persistent left navigation paired with a lightweight top toolbar for actions and context.

## 09. Mail-Style Three-Zone Navigation
Global sidebar, contextual list navigation, and detail content kept visually distinct.

## 10. Settings Sidebar
A quiet, information-dense sidebar with section groups, selected-row emphasis, and almost no decoration.

## 11. Spotlight Command Surface
Navigation hidden behind a global search/command surface that appears above the content plane.

## 12. Command-K Glass
A compact keyboard-first navigation trigger represented by a floating pill or command-field capsule.

## 13. Large-Title Collapse
A large page title at the top smoothly shrinks into a compact navigation title as the user scrolls.

## 14. Scroll-Minimized Navigation
The navbar subtly compresses or slides away while scrolling, restoring itself when the interaction needs it.

## 15. Scroll-Edge Glass
Navigation starts visually light at the content edge, then gains stronger separation as the content passes underneath.

## 16. Frosted System Rail
A translucent vertical navigation rail floating independently from the page edge.

## 17. Sidebar-as-Overlay
Sidebar sits above the content layer and can temporarily cover content without permanently reflowing it.

## 18. Floating Sidebar
An inset rounded sidebar with generous margins, shadowless depth, and a calm selected-state background.

## 19. Compact Icon Rail
A narrow rail carrying familiar glyphs, expanding into labels on demand.

## 20. Mac Finder Column Rail
Hierarchical navigation progresses across columns instead of relying on stacked dropdowns.

## 21. Safari Segmented Control
A compact segmented navigator using a moving selection capsule rather than underlines.

## 22. iOS Picker Strip
Horizontally scrollable text destinations with the selected item becoming the visual anchor.

## 23. Toolbar Segments
Navigation and controls share a segmented top bar with grouped semantic actions.

## 24. Apple TV Focus Navigation
Large targets, strong focus state, spatial movement, and directional navigation optimized for distance interaction.

## 25. watchOS Compact Ring
Very compact navigation that prioritizes one task at a time and relies on recognizable symbols.

## 26. visionOS Spatial Bar
Navigation appears as a floating plane in space with depth, translucency, and contextual placement.

## 27. visionOS Ornament
Controls live around the edge of an app surface as detached floating ornaments.

## 28. Spatial Sidebar
A sidebar-like navigation surface that visually floats beside content instead of occupying a conventional column.

## 29. Glass Island
An intentionally detached island containing logo, primary links, search, and account controls.

## 30. Glass Dock
Bottom or side navigation styled like a highly polished application dock.

## 31. Dock + Utility Bar
Primary destinations in a dock, with search, notifications, and account tools separated into a utility strip.

## 32. Handoff Header
Navigation visually transitions between contexts, making the current destination feel like a continuation rather than a page reset.

## 33. Apple Store Product Nav
Minimal global navigation, large visual content, and compact contextual controls that appear when relevant.

## 34. Product-Page Floating Nav
Navigation overlays immersive content and gains contrast only where it crosses busy imagery.

## 35. Editorial Apple Header
Typography-first navigation with restrained controls and large whitespace.

## 36. SF Symbols Icon Text
Small platform-like symbols support text labels without turning the navbar into an icon-only dashboard.

## 37. Dense macOS Pro Toolbar
More controls than a consumer navbar, but still separated into deliberate groups with predictable placement.

## 38. Contextual Toolbar
Navigation changes to match the current object or task without abandoning the global shell.

## 39. Selection Toolbar
The usual navbar temporarily becomes an action surface when content enters selection mode.

## 40. Search-First Header
Search is the primary interaction and destinations are secondary, useful for large information architectures.

## 41. Utility-Right Header
Brand + primary destination cluster on the left; high-value global utilities stay isolated on the right.

## 42. Split Title Header
Back/navigation controls at the leading edge, page identity centered, actions at the trailing edge.

## 43. Floating Back Control
A tiny translucent back button sits independently over content instead of occupying a full bar.

## 44. Breadcrumb Path Control
Hierarchical navigation is presented as a compact path control rather than a traditional breadcrumb row.

## 45. Capsule Menu
One compact capsule opens a larger contextual navigation surface with a smooth expansion.

## 46. Morphing Tab Bar
Active selection causes the background capsule to physically travel between destinations.

## 47. Context Morph Navbar
The shell subtly changes shape, density, and available actions based on route/context.

## 48. Adaptive Glass Header
Desktop, tablet, and mobile share the same navigation model while changing proportions and placement automatically.

## 49. Monochrome Apple Pro
Near-black/white or neutral surfaces, precise typography, tiny separators, and almost no visual noise.

## 50. Apple Future Hybrid
A synthesis of floating glass, adaptive tabs, scroll minimization, large-title behavior, contextual toolbars, and spatial depth.

# Cross-Style Interaction Ideas

These can be mixed into almost any navbar in the catalog:

### Fluid selection
The active background physically travels between destinations instead of instantly switching.

### Context morphing
Navbar width, controls, and information density change according to the current route.

### Scroll reaction
The shell minimizes while content scrolls and expands when the user reverses direction or reaches the top.

### Magnetic hover
Controls subtly react to pointer proximity without becoming bouncy.

### Focus choreography
Keyboard focus receives the same visual treatment as pointer hover instead of being an afterthought.

### Shared-element transition
The selected navbar item visually carries into the destination page.

### Command palette
⌘K / Ctrl+K opens a searchable navigation layer for deep routes.

### Adaptive collapse
Desktop navigation becomes tabs, a rail, a drawer, or a command trigger according to viewport width.

### Progressive disclosure
Secondary actions appear only when the current task needs them.

### Reduced-motion mode
Every major transition has a calm non-motion equivalent.

### Content-under-navigation
Page content can visually pass behind translucent controls while maintaining readable contrast.

### Depth hierarchy
Global navigation, contextual navigation, and content controls use different visual planes.

# Research Notes

The Apple-inspired section is based on the broad patterns documented in current Apple Human Interface Guidelines: tab bars for top-level navigation, sidebars for broader navigation hierarchies, toolbars for navigation/actions, adaptive tab-bar/sidebar behavior, and Liquid Glass as a functional layer for controls and navigation. Apple also documents navigation bars that can minimize during scrolling in current UIKit guidance.

The broader section intentionally includes patterns associated with major design systems and product categories rather than copying any one product.

Useful primary references:
- Apple Human Interface Guidelines — Tab bars: https://developer.apple.com/design/human-interface-guidelines/tab-bars/
- Apple Human Interface Guidelines — Toolbars: https://developer.apple.com/design/human-interface-guidelines/toolbars/
- Apple Human Interface Guidelines — Sidebars: https://developer.apple.com/design/human-interface-guidelines/sidebars/
- Apple Human Interface Guidelines — Materials / Liquid Glass: https://developer.apple.com/design/human-interface-guidelines/materials
- Apple WWDC26 — Modernize your UIKit app: https://developer.apple.com/videos/play/wwdc2026/278/
- IBM Carbon — UI shell header: https://carbondesignsystem.com/components/UI-shell-header/usage/
- IBM Carbon — UI shell left panel: https://carbondesignsystem.com/components/UI-shell-left-panel/usage/

## Rule for future additions

When adding a new navbar concept:
1. Give it a distinct structural idea, not just a new color.
2. State the interaction model.
3. State the responsive behavior.
4. State what makes it visually different.
5. Avoid treating a brand name as a literal instruction to clone that brand.
